# LPスキルセット

このディレクトリを配布用LPスキルセットの管理元とします。実際に利用する環境のスキルは、更新後の配布物から別途導入します。

- `skills/`：4スキルの編集元。SKILL.md・テンプレート・参照資料・検査スクリプト。
- `manual/`：HTMLマニュアルと練習素材。
- `START.html`、`README.txt`：利用者向けの開始案内。
- `VERSION`：セット全体のバージョン。
- `CHANGELOG.md`：各版の変更内容。
- `build_release.py`：検証・配布ZIP作成。
- `releases/`：配布ZIPとSHA-256。過去版は上書きしない。

## 更新手順

1. このディレクトリ内の対象ファイルを編集する。ローカルに導入したスキルだけを変更して完了しない。
2. `VERSION`を更新し、`CHANGELOG.md`に変更内容を追記する。
3. リポジトリのルートで `python skill-packages/lp-skill-set/build_release.py` を実行する。
4. ZIP内のSTART.htmlと必要な素材・スキルを確認する。LPに関わる変更はスマホ・PCで確認する。
5. ソースと配布物を同じコミットに含めてGitHubへ送る。
6. `lp-skills-vバージョン番号` のGitタグで配布時点を記録する。

バージョンの目安：互換性を壊す変更はメジャー、機能追加はマイナー、修正や資料・配布構成の変更はパッチを上げる。4スキルはセット単位で管理する。
