Problem

良いサービスなのに、LPで伝わりきっていない。

01

最初の3秒で価値が伝わらない

誰向けで、何が得られるのかが曖昧だと、読み進める前に離脱されます。

02

スマホで文章が重く見える

PC前提の幅や余白のままだと、スマホでは情報量が多く感じられます。

03

申し込み場所が遠い

気持ちが高まった瞬間にCTAが見つからないと、行動が止まります。

Offer

このテンプレートで作れるLP

縦長LPに必要な基本構成を、スマホ幅で最初から用意。

ヒーロー、悩み、解決策、特徴、実績、流れ、FAQ、CTAまで入っています。文章と写真を差し替えれば、公開前の初稿としてすぐ使えます。

Reason

スマホファーストで組む理由

1

本文幅が一定なので、読み心地が安定する

PCでも中央のLP本体はスマホ幅のまま。制作中の見え方と実際のスマホ体験がズレにくくなります。

2

PC閲覧ではサイドバーで迷わせない

左にナビ、右にCTAを固定することで、長いLPでも現在地と申し込み導線を保てます。

3

スマホでは余計な装飾を消す

スマホ画面ではサイド要素を非表示にし、本文と固定CTAだけを見せます。

Flow

差し替えの流れ

  1. Step 01

    サービス名とCTAを変更

    ロゴ、ボタン文言、リンク先を実案件に合わせます。

  2. Step 02

    見出しと本文を変更

    悩み、特徴、実績、FAQをお客様向けの言葉に差し替えます。

  3. Step 03

    写真を変更して確認

    スマホ幅で全体を確認し、文字量と余白を整えます。

FAQ

よくある質問

このレイアウトはPCでもスマホ幅になりますか？

はい。PCでは中央のLP本体をスマホ幅に固定し、左右にサイドバーを表示します。スマホではサイドバーを消して本文だけを表示します。

どんな案件に使えますか？

店舗、セミナー、個別相談、スクール、キャンペーン告知、採用説明会など、縦長で説得するLPに向いています。

画像がまだなくても作れますか？

仮画像のまま構成を作り、後から実写真や生成画像に差し替えられます。
