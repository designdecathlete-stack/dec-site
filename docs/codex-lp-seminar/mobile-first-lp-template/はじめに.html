MOBILE FIRST LP / STARTER KIT

原稿と画像を入れて、
自分のLPをつくる。

スマートフォンを基準にした、最大幅480pxのLPテンプレートです。白とグレーをベースに、業種に合わせて色を変更できます。

01　まず、このフォルダを複製

ZIPを展開して、lpフォルダを制作する店舗・サービス用にコピーしてください。lp/index.htmlをブラウザで開くと表示できます。

はじめに.html … この使い方ガイド
lp/ … 制作・公開するフォルダ
  index.html … 原稿・構成・画像の差し替え
  style.css … 色・文字・レイアウト
  script.js … 予約先URLの共通設定
  assets/ … 写真・生成画像の保存先
    hero-placeholder.svg … 仮画像

外部フォント・ライブラリは使っていません。ビルド作業は不要です。

02　Codexに原稿を流し込んでもらう

ヒアリング結果や確認済みの原稿を渡し、次のように依頼します。

このlpフォルダのテンプレートに、下記の原稿を流し込んでください。
スマートフォンファーストのレイアウトを保ってください。
不明な情報は補わず、未確認として知らせてください。
不要なセクションと対応するPC目次は削除してください。
店名・料金・オファーは、ページ内のすべての表示箇所で統一してください。

仮の原稿、○表記、写真枠は差し替えて使います。実績・口コミ・比較は実際の情報がある場合だけ掲載してください。

03　色をまとめて変更する

style.css冒頭の:rootに色を集約しています。まずは--brandを変更すると、ボタン・強調文字・見出しラベルがまとめて変わります。

--brand: #343b3a;       /* メインの色 */
--on-brand: #ffffff;    /* ボタンの文字 */
--text: #292e2d;        /* 本文 */
--muted: #666e6b;       /* 補足文字 */
--page: #ffffff;        /* LP本体の背景 */
--soft: #f4f5f2;        /* 淡い背景 */
--canvas: #eceeeb;      /* PCの外側背景 */
--line: #dadeda;        /* 罫線 */
--placeholder: #e7eae5; /* HTMLの仮写真枠 */
チャコール深いグリーンくすみローズ
このLPのメインカラーを #405d4e に変更してください。
白いボタン文字が読みやすい配色にし、スマートフォン表示を確認してください。

画像に描かれた文字や背景色はCSSでは変わりません。画像側の編集・再生成が必要です。仮のSVG画像も同様です。

04　生成画像を差し込む

ファーストビュー

写真だけを入れる場合は、assetsに画像を保存し、hero-placeholder.svgの参照先を変更します。画像の比率に合わせてHTMLの幅・高さも調整します。

キャッチコピー入りの画像を使う場合は、冒頭の文章と写真を画像1枚に置き換えます。見出しは画面読み上げ用に残し、同じ文字が画面に二重に出ないようにします。

assets/hero.webpを、文字入りのファーストビュー全体として差し込んでください。
画像を切り取らず、横幅いっぱい・高さ自動で表示してください。
既存のキャッチコピー表示は重複させず、h1はsr-onlyにして残してください。
画像の内容が伝わるaltを付けてください。

オファー・CTA

オファーはoffer-textの内容を画像に置き換えます。CTAはdata-reservationが付いたリンクの内側に画像を入れると、予約先の共通設定をそのまま使えます。コード内に差し替え例があります。

この配布物には完成した広告画像や実写真は含まれていません。見本枠を、ご自身の画像に差し替えてください。

05　予約先を1か所で設定する

script.jsのreservationUrlに、実際のLINE・予約フォームなどのURLを入れます。ページ内・PC右側・スマートフォン下部のボタンに反映されます。

const LP_SETTINGS = {
  reservationUrl: "https://実際の予約先URL",
};

空欄のときはページ内の予約案内に移動し、「予約先は未設定」と表示します。実在する別店舗やサンプル宛先には送信しません。

設定するURLはhttps://またはhttp://から始まるものを使います。電話のリンクはtel:形式にも対応しています。

06　Googleマップを設定する

店舗情報の下に、Googleマップの埋め込み枠があります。初期状態は未設定のため、地図の差し替え枠を表示します。

  1. Googleマップで店舗を開き、「共有」から「地図を埋め込む」を選びます。
  2. コピーしたHTMLの中にある src="…" のURLだけを、script.jsのgoogleMapsEmbedUrlに入れます。
  3. 「リンクを送信」で取得した店舗URLをgoogleMapsUrlに入れると、「Googleマップで開く」ボタンも表示されます。

Codexには、取得した埋め込みHTMLと共有リンクを渡して「この店舗のGoogleマップを設定して」と依頼できます。

埋め込みURLと通常の共有リンクは別のものです。地図の表示にはインターネット接続が必要です。公開前に店舗名と所在地が正しいか確認してください。

07　確認して、公開する

  1. 店名・料金・条件・口コミなどを確認し、仮の文言や不要なセクションを取り除きます。
  2. スマートフォンで画像・文章・固定ボタンを確認します。PC（画面幅1024px以上）は中央にLP、左側に追従メニュー、右側に初回オファー・料金・CTAを固定表示します。本文と右側のオファー内容・価格・適用条件はそろえてください。
  3. 予約ボタンを押し、設定した申込み先に移動するか確認します。
  4. 本番公開時に検索掲載を希望する場合は、index.htmlのnoindex, nofollow行を削除します。初期状態は練習用の検索除外指定です。非公開・アクセス制限ではありません。
  5. index.htmlが直下にある「lp」フォルダをNetlify Dropにアップロードします。このガイドを含む外側のフォルダではありません。
  6. 公開URLをスマートフォンで開き、画像・FAQ・予約先を最終確認します。

応用　複製して、別の訴求を試す

lpを別名でコピーし、「手軽さ」「安心感」など訴求の違う原稿・画像に差し替えます。料金・提供条件などの商品情報は共通にします。
